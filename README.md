# What's Cooked — website

Single-page site for **whatscooked.github.io**.

- `index.html` — landing page (English / اردو toggle)
- `privacy.html`, `delete-account.html` — needed for the Play Store listing
- `videos/` — how-it-works videos (add `whatscooked-how-it-works-ur.mp4` + `poster-ur.jpg` and the Urdu tab switches on by itself)
- `assets/` — logo and icons

To show the WhatsApp button and social links, fill in `CONFIG` near the bottom of `index.html` (and `WA` / `EMAIL` in the two policy pages).
